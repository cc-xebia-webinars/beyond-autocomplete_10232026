## Webinar Overview

### Description

Autocomplete is table stakes. This session covers agentic coding tools that plan, execute, and iterate across your entire codebase — and what it actually takes to work with them effectively on real engineering tasks.

### Agenda

- The shift from inline suggestions to autonomous agents: what changes and what breaks
- How Copilot Agent Mode works: task planning, multi-file edits, terminal access, and iteration
- How Claude Code works: context gathering, tool use, and the approval/review workflow
- Practical patterns for high-leverage tasks: refactors, test generation, debugging sessions, and greenfield features
- Keeping agents on track: when to intervene, how to structure prompts, and how to review agent output
- Team adoption considerations: repo hygiene, context quality, and fitting agents into existing workflows
